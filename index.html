TETR.IO Bot

Python · numpy · Pillow · pytest · 2026

A macOS bot that plays TETR.IO by reading the screen in real time, plus a coaching mode that watches a human play and shows where the next piece should go without pressing a key.

  • ~10 msto score ~1,000 board positions per move
  • 5search algorithms working together
  • 5,081opener and perfect-clear setups encoded
  • 92tests, incl. a simulator and a fake game screen
  • Weighs about 23 candidate placements per piece, including tucks, spins and SRS+ wall kicks, using a cheapest-key-path move generator, a backtracking setup solver, a time-limited perfect-clear solver, a beam search and a heuristic with lookahead.
  • Coaching mode recognizes which setup a player is building by elimination against the setup library, ranked by a prior learned from self-play.
  • About 11,200 lines of Python, written with Claude Code and GitHub Copilot while I owned the architecture and design decisions.

FGO Team Finder

Dart · Flutter · 2026

A feature added to a fork of the open-source Chaldea app for Fate/Grand Order. Given the servants a player owns and a quest, it searches for teams that clear the quest in 3 turns, using the app's own battle engine to try skill order, targets, NP order and mystic-code swaps.

  • 5,169candidate teams from a 24-servant box
  • top 3%where the ranking puts the known clearing lineups
  • 0 → 7clears found in the same 6 minutes after the new ranking
  • 194tests, plus a battle-engine search over real game data
  • Ranks every team by estimated NP damage (ATK, class rate, card type, trait bonuses and stacked buffs) so the likeliest teams are searched first, then spends more search on the best-ranked ones under a 10-minute budget.
  • Warns before a long search, shows the full team with each craft essence and the mystic code, and retries a clear with drop-only craft essences when it overkills the quest.
  • About 3,000 lines of Dart and 3,000 lines of tests, written with Claude Code while I owned the design decisions. It does not yet find every clear: one known team needs about 500 search turns and is not reached.
Source on GitHub (fork of chaldea-center/chaldea)
